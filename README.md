# 🚀 Angular-VmtDev

Proyecto base en Angular para el frontend de un ERP.

## 📋 Descripción

Este proyecto contiene la estructura inicial de una aplicación Angular.  
Incluye la configuración para desarrollo local, compilación, y pruebas básicas.

---

## 🖥️ Servidor de desarrollo

Para iniciar el servidor local, ejecuta:

```bash
ng serve
```

## ⬇️ Clonar dependencias

```bash
git clone https://github.com/alexyepez-dev/Angular-VmtDev.git
```

## 📂 Navegar a la carpeta

```bash
cd Angular-VmtDev
```

## 🛠️ Generar componentes

```bash
ng generate component nombre-componente
```

## 📦 Compilar el proyecto

```bash
ng build
```
